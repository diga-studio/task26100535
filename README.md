# cloudquota

云资源多级（租户 / 部门 / 用户）配额核账库，纯进程内存实现，供上层直接调用。

## 用法

```go
l := quota.NewLedger(cfg)        // cfg 固定层级关系与各层四项上限
ok := l.Approve(req)             // 批准请求：三层四项上限全部满足才占额
l.Revise(rev)                    // 计费修订：较大修订号整体替换实账快照
l.Close(reqID)                   // 关闭：释放在用占用，保留实账（幂等）
rep := l.Query(userID, month)    // 查询：同一一致时刻的三层用量与月度预算视图
```

- 金额一律为整数分；预算占用 = max(当月预估, 最新累计实账)，关闭后只保留实账。
- 所有操作由单一互斥锁串行化，每次操作整体生效，查询不会看到中间状态。
- 告警阈值：<80% OK，[80%,95%) WARNING，[95%,100%) CRITICAL，>=100% BLOCKED。

## 测试

```sh
go test ./...
```

覆盖：并发争抢租户最后名额、计费修订全生命周期（含关闭后修订与旧修订重放）、
